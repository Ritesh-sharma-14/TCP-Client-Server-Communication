# TCP Client Server Communication

## Description
A Python-based TCP client-server communication project using socket programming.

## Features
- TCP socket communication
- Client-server architecture
- Message exchange
- Error handling

## Technologies
- Python
- Socket Programming
- TCP/IP

## Project Structure

TCP-Client-Server-Communication/
│
├── client/
│   └── client.py
│
└── server/
    └── server.py

## Run

Start server:

python server/server.py

Start client:

python client/client.py
